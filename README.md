# 👤 Mechanix Contacts

Contacts App lets you manage contacts, built with Flutter Elinux for Mechanix OS. It provides a simple and intuitive interface for managing your contact list.

## 📦 Install Guide

### 📝 Pre-requisites:

* [Flutter-Elinux SDK](https://github.com/flutter-elinux/flutter-elinux)
* [Dart SDK](https://dart.dev/get-dart)

### 🚀 Steps to run Contacts App:

1. Clone the repository:

```bash
$ git clone https://github.com/mecha-org/mechanix-contacts
$ cd mechanix_contacts
```

2. Install Flutter dependencies:

For flutter-elinux:

```bash
$ flutter-elinux pub get
```

3. Build and Run:

For flutter-elinux:

```bash
$ flutter-elinux build
$ flutter-elinux run
```

## 🔑 Key Features

* **Contacts Management**: Create, edit, search, and delete contacts.
* **Contact Details**: Store and manage multiple phone numbers and email addresses for contacts.
* **Search Contacts**: Quickly find contacts by name or phone number.
